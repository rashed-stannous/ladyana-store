# Ladyana Store
Responsive Ladyana shopping prototype with a compact mobile header and hero, product search, collections, wishlist, cart, checkout preview and sample order tracking.

## Run
Requires Node.js 22 or newer. Run `npm ci`, then `npm run dev`. Run `npm run build` to create `dist/`.

## Vercel
Import this repository, choose Vite, use `npm run build` and output directory `dist`.

## Current status
Products and prices are samples. Checkout, payment options, order tracking and newsletter are simulated. No payment is collected, and no customer information is stored remotely. Supabase database and authentication are not connected yet. Do not use this preview to accept real orders.
